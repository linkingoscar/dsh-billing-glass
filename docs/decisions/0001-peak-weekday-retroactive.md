# 0001 — 峰谷「周一至周五」限定的回溯口径

状态：已采纳 · 日期：2026-08-23

## 背景

2026-08-17 起官方实行峰谷定价。插件 v0.3.0 依据当时页面快照实现为
「每日 9:00–12:00 / 14:00–18:00 为高峰」。2026-08-23 抓取官方页发现脚注
已明确：**高峰时段为北京时间周一至周五**（周末全天谷价）。

## 决策

`isPeak()` 增加周一至周五判定，且**回溯适用至 2026-08-17 政策起点**，
不拆分政策条目。

## 备选方案

1. 拆成两条政策（8-17 无限定 / 8-23 起工作日）——被否：官方从未声明
   过渡日期，拆分是编造一个不存在的精确时点，违反本插件"只记录可审计
   区间"的原则。
2. 保持全天峰价不动——被否：与现行官方定义直接矛盾，周末成本会高估一倍。

## 后果

- 周末回放计费按谷价；若平台在 8-17~8-22 实际按"每日峰谷"结算，这几天的
  回放金额会略低于账单。已在 README 已知限制中披露。
- 未来官方若再改窗口定义，沿用同一模式：改现行政策 + 更新本文件 +
  刷新 README 限制披露。
